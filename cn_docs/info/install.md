# ⚙️ 安装

## 安装

* 从官方发布页面下载插件。文件名应为 **UltimateQuest-X.X.X.jar**，其中 X 代表版本号。
* 将 `.jar` 文件放入服务器的 `plugins` 文件夹。
* 关闭服务器后重新启动。<mark style="color:red;">不要在服务器运行时通过其他方式加载插件。</mark>
* 首次启动后，插件会在 `plugins/UltimateQuest/` 中生成配置文件。
* 默认配置用于帮助你了解配置结构。建议先体验默认任务，再根据服务器的实际需求修改。

{% hint style="warning" %}
请勿使用 Bukkit 的 `/reload`、PlugMan 或其他插件热加载器。修改配置后使用 `/uq reload`；更换插件 JAR 时请完整重启服务器。
{% endhint %}

## 开始使用

1. 使用 `/uq` 打开任务菜单。
2. 接取一项任务，例如内置的挖矿任务。
3. 按照要求完成目标。普通任务只统计接取后进行的操作。
4. 返回菜单领取奖励。

其他菜单分别通过 `/uq period`、`/uq scroll`、`/uq battlepass` 和 `/uq milestone` 打开。默认内容见[内置任务](builtin-tasks.md)，管理命令见[命令与权限](commands-permissions.md)。

如需修改默认语言，请编辑 `config.yml` 中的 `config-files.language`。`en_US` 为英文，`zh_CN` 为简体中文。按玩家客户端选择语言和添加自定义翻译的方法见[高级语言管理](../features/advanced-language-management.md)。

## 更新

* 更新前备份 `UltimateQuest` 文件夹；使用数据库时，也请备份数据库。
* 关闭服务器，删除旧版本插件 JAR，再安装新版本。`plugins/` 中只保留一个 UltimateQuest JAR。
* 建议始终将插件更新到最新版本。
* 已有任务和菜单文件会保留。请对照新版默认配置，按需手动合并改动。启动时会补充缺失的内置文件；不需要的内置任务请在其文件中设置 `enabled: false`。
* 语言文件中缺少的内置键会自动补充，已有翻译会保留。
* 每次更新前请仔细阅读更新日志。如果跨越多个版本更新，请阅读中间所有版本的更新日志。重大且不兼容的改动会在其中注明。

更新时请保留玩家数据和卷轴数据，无需通过删除进度来更新插件。

## 重载配置

修改任务、奖励、菜单或语言文件后，使用：

```text
/uq reload
```

如果提示配置错误，请根据报错修改对应文件，再次重载。已经接取或分配的任务会保留原有目标和奖励，因此测试任务修改时应重新接取一项新任务。

更换插件 JAR、安装或删除兼容插件、修改数据库设置后，都需要完整重启服务器。
