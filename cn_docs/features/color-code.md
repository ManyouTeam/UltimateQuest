# 🎨 颜色与文字格式

任务名称、描述、菜单文字和消息可以使用受支持的颜色格式。先在实际显示位置测试，因为聊天、物品 Lore 和菜单标题可能采用不同的文本接收方式。

## 常用写法

以下都是显示字段片段，可放到任务名称或相应文本位置：

```yaml
name: '&a绿色任务'
```

`&a` 是绿色，`&6` 是金色，`&c` 是红色。YAML 中以 `&` 开头的文字要加引号。

精确颜色可用六位十六进制值：

```yaml
name: '&#60A5FA采石任务'
```

插件也识别成对渐变端点写法：

```yaml
name: '&<#60A5FA>采石任务&<#22D3EE>'
```

是否显示完整渐变取决于实际文本解析路径和接收组件，不要只在一个界面测试后就假设所有位置效果相同。

## MiniMessage

`config.yml` 的 `config-files.force-parse-mini-message` 控制是否强制 MiniMessage 解析。使用这种格式前，确认接收字段的解析方式，再测试颜色标签，例如：

```yaml
name: '<green>采石任务</green>'
```

避免在同一条文本中随意混合多种写法，排查时先用一种简单颜色确认解析生效。

## 语言文本的颜色格式

先按[语言管理](advanced-language-management.md)定义翻译，再引用，例如：

```yaml
name: '&a{lang:tutorial.mining-name}'
```

如果出现原始代码或文本没变，检查引号、配置位置和翻译键，执行 `/uq reload` 后重新打开菜单。已接任务的显示可能来自保存的定义，测试时也要考虑这一点。
